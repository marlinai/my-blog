💡 推荐的 Token 最小权限配置：

1. 访问 GitHub -> Settings -> Developer settings -> Personal access tokens -> Fine-grained tokens

2. 点击 Generate new token

3. Repository access 选择 "Only select repositories" 并指定你的博客仓库

4. Permissions 找到 Contents 并设置为 Read and write
